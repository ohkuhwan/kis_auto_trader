## 이번 재감사에서 수정한 사항

- YAML 조건이 최종 액션을 정하더라도 프리셋의 공식 strength 값을 `0.70/0.80`으로 무조건 덮어쓰지 않도록 수정했습니다.
- 공식 전략과 비교해 모멘텀 매도 `0.80`, 52주 고점 매수 `0.85`, 돌파 실패 매도 `0.90`, 추세 필터 매수/매도 `0.65` 강도를 보정했습니다. 내부 프리셋과 YAML 지표의 breakout/high lookback 범위도 일치시켜 회귀 테스트를 추가했습니다.
- `kis_strategy_test.py`가 결과 JSON을 `KIS_LOG_DIR`에 기록하도록 바꾸고, 온라인 시세 테스트에서 `KIS_PAPER=false`를 거부하도록 했습니다.
- 감시 테스트 harness의 임시 설정 경로를 실제 프로젝트 패키지와 분리해 테스트 종료 지연을 줄였습니다.

## 안전 경계 및 제한

- 이번 검증에서는 KIS 인증, 실제 API/REST, WebSocket, 주문/취소 POST를 실행하지 않았습니다.
- 온라인 시세 테스트는 `KIS_PAPER=true`만 허용하며 주문 API를 호출하지 않습니다.
- 공식 `week52_high`는 현재가 API의 `w52_high`를 사용하지만, 내부 엔진은 최근 252거래일 일봉 고가를 사용합니다. 추가 REST 호출을 억제하기 위한 문서화된 차이이며, 공식 데이터 소스와 완전히 같은 값임을 보장하지 않습니다.
- 종목 DB에는 ETF·우선주 등 equity 유형 상품도 포함되어 있어 별도 분류 열 없이 보통주만으로 제한하지 않습니다.
- 최종 배포 ZIP `kis_auto_trader_v7_0_0.zip`을 생성했습니다. ZIP에는 현재 V7.0.0 소스와 문서 147개 파일이 포함되며 `.env`, `.venv`, 운영 `logs/`·`json/`, 토큰/상태/주문 감사 파일, JSONL, 캐시, pycache 및 백업은 포함하지 않았습니다.
