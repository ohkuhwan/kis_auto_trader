# CHANGELOG V7.1.3

## 자동 모니터링 시작 시간 및 런타임 버전 표시 수정

- 자동 시작은 한국시간(Asia/Seoul) 기준 08:00 이전에 실행되지 않도록 제한합니다. 08:00 정각부터 기존 평일·휴장일·수동 중지·모니터링 비활성화·종료 시각 정책을 적용합니다.
- `monitoring/watchdog.sh`의 사전 검사와 Proot 잠금 획득 후 재검사, `scripts/request_start.sh`의 잠금 획득 후 정책 재검사에 시작 시각 조건을 각각 적용했습니다. 경합 또는 지연 중 시각이 바뀌어도 자동 시작 정책을 우회하지 않습니다.
- 운영자가 `scripts/start.sh`로 요청하는 명시적 수동 시작은 이번 자동 시작 제한의 대상에서 제외했습니다.
- 애플리케이션 시작/종료, 오류 및 Telegram 알림과 systemd 단위 설명의 잘못된 구버전 표시를 V7.1.3으로 정리했습니다. 과거 버전의 변경 이력 및 역사 문서는 보존했습니다.
- 신규 매수 가능 시간(기본 09:10~15:10)과 매매 판단·주문 로직은 변경하지 않았습니다.

## 검증 범위

- 08:00 이전 watchdog 자동 시작 차단 및 잠금 내부/시작 요청 최종 재검사
- Bash 구문 검사, 모니터링 스크립트 회귀 테스트, 버전 표기 검사
