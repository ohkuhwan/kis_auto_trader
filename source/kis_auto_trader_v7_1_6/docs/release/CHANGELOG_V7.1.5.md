# V7.1.5 변경사항

## 운영 설정 및 주문 안전성
- 종료 시 미체결 취소 최종 확인 대기시간을 최소 180초로 상향했습니다.
- BUY/SELL 미체결 취소 기준을 각각 최소 300초로 상향했습니다. 기존 `.env`에 180초가 남아 있어도 코드에서 300초 미만을 허용하지 않습니다.
- `MAX_POSITIONS`에 따라 가용 주문가능 현금을 남은 포지션 슬롯 수로 나누어 주문 예산을 계산합니다.
- root/systemd watchdog이 생성하는 `watchdog_*.log`, `start_request_*.log`를 로그 디렉터리 소유자/그룹과 정렬하고 그룹 쓰기 권한을 적용합니다.

## 기존 V7.1.5 안전성 개선 유지
- 종목별 500분 재매수 쿨다운 및 재시작 복구
- 당일 +25% 이상 / -15% 이하 종목 신규 매수 제외
- 일봉 캐시와 KIS10/CUSTOM/보유종목 청산 평가 데이터 공유
- strong_close 0 범위 처리, 데이터 부족과 API 오류 구분
- WebSocket 중복 구독 방지 및 재연결 후 REST 대사
- Telegram 민감정보 로그 차단

## 테스트
- V7.1.5 기존 테스트 전체를 회귀 기준으로 실행하고 V7.1.5 신규 테스트를 추가합니다.
