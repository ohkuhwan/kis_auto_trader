# V7.0.0 상세 시스템 흐름도

상세 PNG 다이어그램은 다운로드 크기를 줄이기 위해 배포 ZIP에서 제외했습니다. 편집 가능한 Mermaid 원본은 [`V7.0.0_SYSTEM_FLOW.mmd`](V7.0.0_SYSTEM_FLOW.mmd)입니다.
GitHub, VS Code Mermaid 확장 또는 Mermaid Live Editor에서 Mermaid 원본을 열 수 있습니다.

## 다이어그램 범위

1. 시작·설정·복구: `.env`, 런타임 경로, 상태 복구, 휴장일 판정, KIS REST/WebSocket 준비
2. 후보 수집: `ENTRY_MODE`의 HTS / BUILDER / ALL 분기, 내부 10개 전략 평가와 프로필 투표
3. 매수 안전 게이트: 시간·손실·거래횟수·중복/쿨다운·현금·수량·주문 활성화 여부
4. 보유 청산: 실시간 시세와 전략/손절/익절/트레일링 조건을 통한 매도 판정
5. 체결 및 대사: 체결 중복 방지, REST 잔고·체결·미체결 대사, 불명확 주문 잠금
6. 보호 루프: 주기 제한, API 호출 상한, 오래된 시세, 종료 절차
7. 별도 감시: systemd/Proot watchdog, 수동 정지 표식, 시작 정책
8. 운영 파일: 상태·토큰·불명확 주문·취소 주문·휴장일·전략 신호 로그

## 중요한 해석

- `KIS_PAPER=true`는 모의투자 API 환경 선택이고 `KIS_ENABLE_TRADING=false`는 주문 POST 차단입니다. 서로 다른 설정입니다.
- 주문 POST 응답이 불명확하면 `UNCERTAIN_ORDERS_FILE` 잠금을 유지합니다. 조회만으로 확정되지 않은 주문을 자동 재전송하지 않습니다.
- 체결 통보는 즉시 반영하지만 REST 체결/미체결/잔고 대사로 교차 확인합니다.
- `risk_source_strategy`는 현재 프로필당 **단일 전략 ID**를 받습니다. 여러 전략의 위험값을 함께 쓰려면 최댓값/최솟값/우선순위 중 어떤 결합 규칙을 적용할지 먼저 정의해야 하며, 현재 구현은 목록형 다중 전략을 지원하지 않습니다.
- 다이어그램은 소스의 논리 흐름을 설명하며 스레드·콜백 간 모든 시간 순서를 보장하는 시퀀스 다이어그램은 아닙니다.
